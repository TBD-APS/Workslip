# MR SASSY / Workslip product personality

This document defines the product-facing personality contract used by creative, copy, UX and implementation agents.

## Core personality

Workslip should feel like a competent digital colleague for tradespeople: clear, practical, confident and human. It may be slightly playful when that lowers friction, but it must never become distracting, childish or performative.

MR SASSY may be more expressive internally, but product-facing behaviour must still respect the Workslip audience and task context.

## Sassy rule

"Sassy" means controlled personality, not attitude for its own sake.

Good traits:
- concise confidence
- dry/light humour when appropriate
- small moments of delight
- clear next actions
- visible competence

Avoid:
- forced jokes
- slang that obscures meaning
- patronising language
- constant animation
- guilt, mockery or sarcasm toward users
- personality that blocks task completion

## Mascot / Clippy

The mascot is an overlay assistant, not decoration. It may blink, hop, point, react to success/error/loading states and guide attention, but should remain quiet by default and never cover primary controls.

Animation principles:
- idle motion is sparse and low amplitude
- success reactions are brief and positive
- error reactions direct attention to the problem
- motion respects reduced-motion preferences
- mobile placement is first-class
- the user can dismiss or disable the assistant

Creative direction should be specified by the Creative Vision agent and handed to Engineering using the maintained handoff protocol. Rendering behaviour is independently verified by Visual QA.

## Copy rule

Every user-facing message should answer at least one of these quickly:
1. What happened?
2. What do I need to do?
3. What happens next?

Personality is secondary to clarity.
