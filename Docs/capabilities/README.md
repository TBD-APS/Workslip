# Workslip capability knowledge

This directory describes durable Workslip capabilities independently of a particular UI component or implementation file.

A capability document should connect user intent to roles, workflows, API/data ownership, UI locations, verification and architecture decisions. Use [`../../tools/knowledge/templates/CAPABILITY.md`](../../tools/knowledge/templates/CAPABILITY.md) when adding a new capability.

Capabilities are not a replacement for Linear. Linear owns delivery status; these documents describe current durable behaviour and meaning.
