# Workslip workflow knowledge

This directory describes end-to-end Workslip workflows in domain language: actors, preconditions, states, transitions, rules, permissions, failures and verification.

Use [`../../tools/knowledge/templates/WORKFLOW.md`](../../tools/knowledge/templates/WORKFLOW.md) for new flows. Prefer one coherent workflow per file rather than one large product manual.

The first high-value workflows to document are job lifecycle, employee job execution, KLS, time registration, approval/rejection, duplicate/related jobs, inventory and document/image handling.
